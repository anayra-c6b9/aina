# aina

A declarative configuration driven orchestration tool for small micro-service systems

## Intro

aina allows small micro-services to communicate with each other without exposing their identity. \
aina offers the user to declare multi-step routes with data mapping between steps, read-only guard checks before any action, retries, circuit breaking, health checks, compensating (undo) actions and structured error reports that name the failed step. \
aina sits behind a reverse proxy/web server like nginx and servers service-to-service traffic.
